## 📖 Overview

> 🧪 **Lab Environment:** **OWASP ZAP** for penetration testing and vulnerability scanning, with a model trained using **Scikit-learn**.

This lab shows how **AI-driven techniques** can enhance traditional **penetration testing and vulnerability management**. You set up OWASP ZAP for penetration testing and vulnerability scanning, extracted and structured the ZAP results into a dataset, trained a Scikit-learn model to predict vulnerability severity, and integrated that model with ZAP for automated vulnerability classification and enhanced remediation strategies.
