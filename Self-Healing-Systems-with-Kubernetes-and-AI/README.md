## 📖 Overview

> 🧪 **Lab Environment:** A local Kubernetes cluster running on **Minikube**.

This lab combines **Artificial Intelligence** with **Kubernetes** to build a **self-healing system**. You set up a local cluster, trained an AI model to detect system anomalies such as CPU and memory spikes, and integrated that detection with Kubernetes so the cluster can respond on its own, by scaling or restarting pods, without manual intervention.

## 🔑 Key Concepts

| 💡 Concept | 📖 Description |

| **Anomaly Detection** | Using an AI model to identify abnormal behavior, such as CPU or memory spikes |
| **Self-Healing System** | A system that automatically recovers from faults without manual intervention |
| **Pod Scaling** | Adjusting the number of running pods in response to detected load |
| **Pod Restart** | Restarting pods automatically to recover from detected faults |
| **Real-Time AI Insights** | Monitoring data analyzed as it arrives to drive automated actions |
| **Predicted Behavior** | Using the AI model's predictions to trigger scaling and fault recovery |
