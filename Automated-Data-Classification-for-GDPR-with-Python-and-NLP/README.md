## 📖 Overview

> 🧪 **Lab Environment:** Python with **spaCy** NLP, working on a sample dataset simulating real-world personal data.

This lab uses **Natural Language Processing (NLP)** to support **GDPR compliance**. You loaded and processed a sample dataset simulating real-world personal data (name, email, phone, address), used spaCy to extract and classify that data into GDPR-compliant categories, tagged which fields contain personal or sensitive information, generated a compliance report, and visualized the distribution of GDPR-related data.
