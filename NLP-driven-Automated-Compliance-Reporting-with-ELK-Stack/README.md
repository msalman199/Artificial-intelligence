## 📋 Overview

This lab combines observability and AI to streamline compliance reporting. You install and configure the **ELK Stack** on Ubuntu, ingest local system logs and visualize them in **Kibana**, apply **NLP techniques** to extract compliance-relevant insights from log messages, and automatically generate a **compliance risk report** based on sentiment and pattern analysis.

> 🖥️ **Lab Environment:** Everything runs **completely offline** on your Ubuntu machine.
