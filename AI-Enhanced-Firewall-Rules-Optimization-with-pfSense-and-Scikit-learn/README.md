## 📖 Overview

> 🧪 **Lab Environment:** **pfSense** firewall with traffic logs analyzed using **Scikit-learn**.

This lab applies **AI and machine learning** to **firewall management**. You set up pfSense to manage firewall rules and capture traffic logs, then used Scikit-learn to analyze that traffic data and identify patterns such as high-volume or suspicious traffic. The resulting insights were used to suggest firewall rule optimizations, such as blocking or rate-limiting high-risk traffic.
