## 📖 Overview

> 🧪 **Lab Environment:** **Snort IDS** monitoring network traffic, with an AI model trained using **PyTorch**.

This lab shows how **AI** can enhance **intrusion detection systems**. You set up Snort IDS to monitor network traffic for intrusions, preprocessed historical intrusion logs to train a PyTorch model that classifies traffic as normal or intrusive, and integrated the trained model with Snort for real-time intrusion detection and self-healing actions based on AI insights.
