## 📋 Overview

This lab introduces **machine learning observability into CI/CD**. You build a local pipeline with **Jenkins**, log and track build/deploy durations across multiple runs, and integrate **MLflow** to monitor and visualize performance trends, enabling data-driven decisions about pipeline efficiency.

> 🖥️ **Lab Environment:** The entire workflow runs **offline**.
