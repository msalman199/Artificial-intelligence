## 📋 Overview

This lab combines real-time monitoring with machine learning. You set up **Prometheus** and **Grafana**, collect time-series data through the Prometheus **HTTP API**, use **linear regression** to forecast future resource usage, and visualize the predictions to anticipate downtimes or performance issues.

> 🖥️ **Lab Environment:** Everything runs on your **offline Ubuntu environment**.
